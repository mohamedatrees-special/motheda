# متجر المتحدة للأدوات والمهمات الكهربائية
## Al-Motaheda Electrical Supplies — Production Fullstack Platform

منصة التجارة الإلكترونية الشاملة لشركة **المتحدة للأدوات والمهمات الكهربائية**، مصممة خصيصاً لتلبية احتياجات المقاولين، فنيي الكهرباء، وأصحاب المنشآت السكنية والتجارية في جمهورية مصر العربية.

---

## ⚡ المميزات الرئيسية والخصائص المنفذة

1. **واجهة عربية أصيلة مع دعم كامل للـ RTL:**
   - تصميم هندسي واحترافي مستوحى من قطاع الكهرباء والتأسيس.
   - تصنيفات متخصصة: كابلات وأسلاك نحاسية، قواطع ولوحات توزيع، إضاءة وليد، مفاتيح وأفياش، مواسير ولوازم تأسيس، أجهزة قياس.
   - فلاتر فنية دقيقة: حسب الجهد الكهربائي (220V أو 380V ثلاثي الأطوار)، الماركات المعتمدة (السويدي للكابلات، شنايدر إلكتريك، ABB، فينوس، لوجراند، UNI-T).

2. **محرك العروض الترويجية والفلاش سيل (Flash Sales Engine):**
   - بنر فلاش سيل مع مؤقت عد تنازلي متحرك بالساعات والدقائق والثواني.
   - حساب الخصومات بالنسبة المئوية أو المبالغ الثابتة مع أولوية تطبيق العروض server-side.
   - شارات تنبيه انخفاض المخزون الفعلي: `"باقي X قطع فقط في المخزن - اطلب الآن!"`.

3. **مصفوفة الشحن والتوصيل الديناميكية (Dynamic Shipping Matrix):**
   - **وضع الشحن الموحد (Flat Rate):** شحن بسعر ثابت لكافة أحياء المحافظة (مثل الإسكندرية والقليوبية).
   - **وضع التسعير حسب الحي (District Pricing):** تسعير دقيق للأحياء (مثل القاهرة: مدينة نصر 40 ج.م، القاهرة الجديدة 50 ج.م، المعادي 45 ج.م).
   - **استلام مجاني من الفروع (Branch Pickup):** 0 ج.م مصاريف شحن مع اختيار الفرع المعتمد (فرع السبتية المركزي، فرع العتبة، فرع النزهة الجديدة).
   - حظر التوصيل التلقائي للمناطق غير المدعومة مع إظهار رسالة واضحة: `"التوصيل غير متاح لهذه المنطقة حالياً"`.

4. **بوابة الدفع الإلكتروني (Paymob Gateway) والدفع عند الاستلام:**
   - الدفع عند الاستلام أو عند استلام الفرع (نقداً).
   - الربط الكامل مع Paymob: البطاقات البنكية (Visa / MasterCard)، المحافظ الإلكترونية (فودافون كاش، أورنج، اتصالات، WE Pay)، وتقسيط فاليو (valU).
   - التحقق الصارم من توقيع الـ Webhook عبر خوارزمية HMAC-SHA512 الرسمية.
   - منع تكرار المعاملات وحماية العمليات المالية (Idempotency).
   - وضع محاكاة Sandbox تجريبي مدمج بالواجهة لاختبار عمليات السداد بنجاح أو فشل وتحديث المخزون تلقائياً.

5. **تأكيد الطلب الفوري عبر واتساب (WhatsApp Click-to-Chat):**
   - زر بارز في شاشة نجاح الطلب وشاشة التتبع يفتح محادثة واتساب الرسمية مع مسؤول مبيعات المتجر، مجهزة بالرسالة المعتمدة:
     `"مرحباً متجر المتحدة، قمت بعمل طلب جديد رقم #{{order_id}} بقيمة {{total_amount}} ج.م باسم {{customer_name}}. برجاء تأكيد الطلب."`

6. **تتبع آمن للطلبات للزوار (Secure Guest Order Tracking):**
   - نظام حماية يمنع هجمات IDOR عبر تشفير SHA-256 لرموز الوصول وتمريرها في كوكيز HttpOnly الآمنة.
   - إمكانية إلغاء الطلب من قِبل العميل واسترجاع المخزون طالما كان الطلب في مرحلة الانتظار.

7. **لوحة تحكم المشرفين مع المصادقة الثنائية (Admin 2FA & Emergency Resilience):**
   - **المرحلة 1:** التحقق من اسم المستخدم وكلمة المرور المشفرة بـ PBKDF2/salt.
   - **المرحلة 2:** رمز تحقق OTP سداسي الأرقام يتم توليده مشفراً وله صلاحية 3 دقائق بحد أقصى 3 محاولات (مع إشعار Console للمطورين).
   - **رمز استرداد الطوارئ (Emergency Recovery Code):** آلية إنقاذ مشفرة للدخول في حال انقطاع شبكة الرسائل أو الواتساب (`MOTAHEDA-EMERGENCY-2026-X99`).
   - متابعة مؤشرات الأداء (KPIs): الإيرادات المحصلة المعتمدة، قيمة الطلبات الإجمالية، حالة الطلبات، وتنبيهات انخفاض المخزون.
   - محرك إدارة دورة حياة الطلبات (Order Lifecycle State Machine).
   - محرر مصفوفة الشحن وتعديل أسعار المحافظات والأحياء.
   - سجل تدقيق غير قابل للتعديل (Immutable Audit Log) يوثق كافة التعديلات مع اسم المشرف والتاريخ.

## 🚀 تشغيل المشروع والاختبارات

### 1. تشغيل بيئة التطوير المحلية
```bash
npm run dev
```
يعمل الخادم الكامل (Express API + Vite + React 19) على:
`http://localhost:3000`

### 2. تشغيل حزمة الاختبارات الآلية الشاملة
```bash
npm test
```
تختبر الحزمة 41 تأكيداً آلياً تشمل:
- حسابات الأسعار والخصومات والكسور العشرية.
- مصفوفة الشحن والأحياء والاستلام من الفروع.
- حجز المخزون ومنع الشراء الزائد عند نفاد الكميات (Race Conditions).
- التحقق من أرقام الهواتف المصرية (010/011/012/015).
- توقيع Paymob HMAC-SHA512 ومنع تكرار الـ Webhooks.
- المصادقة الثنائية OTP ورمز استرداد الطوارئ.

### 3. فحص التوافقية والأنماط (Lint & Typecheck)
```bash
npm run lint
```

### 4. بناء الحزمة الإنتاجية (Production Build)
```bash
npm run build
```
